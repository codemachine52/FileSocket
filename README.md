# FileSocket — клиент-серверная передача файлов

Приложение на C (WinSock2) для Windows.
Две консольные программы: Server и Client.

## Как запустить
Перейти в **ветку** `ServerApp`. Скачать проект (либо клонировать репозиторий). Аналогично с веткой `ClientApp`.
1. Открыть `Server/Server.sln` в Visual Studio 2022 → Build → Run
2. Открыть `Client/Client.sln` в Visual Studio 2022 → Build → Run

## Команды клиента

`/help` — список команд

`/spaces <файл>` — пробелы в файле на сервере

`/get <серверный файл> <локальный>` — скачать файл

`/put <локальный> <серверный>` — отправить файл

`/exit` — выход
